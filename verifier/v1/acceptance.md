# 验收标准 v1

1. 选题属于数字治理，研究问题清晰，具有相对既有文献的可说明增量贡献。
2. 采用真实公开数据的混合方法设计；定量分析与定性制度比较均实质存在，不以模拟数据或虚构访谈替代。
3. 原始数据、编码规则、分析脚本和输出可复现；所有外部事实与数字在论文中有紧邻的内联来源链接。
4. 定量结果与生成文件一致，披露缺失、样本边界和稳健性；统计方法与样本条件匹配，不把相关关系解释为因果关系。
5. 定性分析采用统一比较维度，包含支持证据、反证或边界条件，结论不超过证据强度。
6. 论文为完整中文学术长文，含摘要、问题提出、文献与理论、研究设计、定量结果、定性比较、综合讨论、结论与局限；图表与正文相互印证。
7. 遵循深研格式：以表格组织比较和结果，静态图像嵌入 Markdown，不设置末尾参考文献表；无占位符、空链接和伪造引用。
8. GitHub 仓库包含论文、数据、代码、图表和复现说明；上传后逐项核验远端关键文件。
