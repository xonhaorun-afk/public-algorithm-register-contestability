# 公共算法登记册的可争议性披露

本仓库保存论文《可见之后，如何质疑？公共算法登记册的可争议性披露——基于荷兰国家算法登记册1,608条记录与版本历史的混合方法研究》及全部复现材料。

研究使用2026年10月28日荷兰国家算法登记册公开快照，区分“知情—理解—质疑—救济”四个披露环节。指标只测量可争议性的必要信息条件，不推断实际申诉、救济效果、公众信任或算法合法性。

## 核心发现

| 指标 | 数量 | 比例 |
|---|---:|---:|
| 知情 | 1,594／1,608 | 99.13% |
| 理解 | 1,183／1,608 | 73.57% |
| 质疑 | 1,548／1,608 | 96.27% |
| 救济词汇 | 173／1,608 | 10.76% |
| 救济导航（人工确认） | 17／1,608 | 1.06% |
| 完整披露链 | 15／1,608 | 0.93% |

17条救济导航分布于7个机构；南荷兰省与阿姆斯特丹合计12条。同一1.0标准内539个首末版本配对中，知情和理解改善，救济词汇基本不变。全站FAQ存在通用投诉与异议路径，因此条目级稀缺不等于公众完全无法救济。

## 一键复现已有快照

建议使用Python 3.12和Node.js。仓库已含论文使用的原始CSV，无需联网即可重跑统计。

```bash
python3 -m pip install -r analysis/requirements.txt
python3 analysis/analyze.py
cd analysis
npm ci
node render_charts.mjs
cd ..
python3 analysis/svg_to_png.py
```

Python依赖版本固定在`analysis/requirements.txt`；ECharts版本固定在`analysis/package.json`与锁文件中。分析脚本以仓库根目录自动定位输入，不依赖当前工作目录。输出会覆盖同名生成文件，但不会修改原始CSV和人工复核表。

## 获取未来新快照

```bash
python3 analysis/download_data.py --snapshot 2026-10-29
```

请把日期改为实际下载日。脚本拒绝使用论文归档日期`2026-10-28`，以防覆盖固定证据。新下载反映网站当时状态，不会自动成为论文输入；若需分析新快照，应同步更新`analysis/analyze.py`中的文件名并重新检查字段制度、救济规则和人工复核。

## 方法与统计边界

- 非占位主门槛为20字符，另报告1与40字符敏感性。
- 联系方式仅指字段内含可机读邮箱、网址或电话，不验证连通性。
- 救济导航要求同字段共现救济词与程序、期限或受理去向；全部22个自动候选均人工复核，另随机复核40条其他救济词命中记录。
- 稀疏救济指标不报告不稳定回归；多变量模型仅用于事件充足的“理解”。
- 版本检验限同一1.0标准，使用McNemar精确检验；跨标准只作非等价描述。
- 机构等权结果使用2,000次bootstrap，固定随机种子为20261028。
